TSE Maaş Hesaplama PWA v3 – Hizmet Yılı

GitHub deposunun ana dizinine ZIP içindeki index.html, app.js, style.css, sw.js, manifest.webmanifest, icon.svg dosyalarını ayrı ayrı yükleyin. Aynı isimli dosyaları değiştirin. ZIP dosyasını tek başına yüklemeyin.

Hizmet yılı başlangıçta 0; her yıl için 26,16 TL aylık hizmet zammı varsayılır. 12 yıl = 313,92 TL. Bu katsayı tek bir bordrodan türetilmiştir, herkes için doğrulanmış resmî tarife değildir. Gerekirse kullanıcı değiştirebilir.
